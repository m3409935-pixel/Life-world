# LIFE WORLD — WEBER FAMILY

Мобильная браузерная игра для двух игроков. Это стартовая версия: общий игровой мир, выбор персонажа, события, чат и сохранение состояния в Supabase.

## 1. Что понадобится
- Аккаунт Vercel
- Бесплатный проект Supabase (для синхронизации между разными телефонами)
- Компьютер удобнее для первоначальной настройки, но можно сделать и с телефона

## 2. Настрой Supabase
1. Открой https://supabase.com и создай проект.
2. В проекте открой **SQL Editor → New query**.
3. Скопируй весь текст из файла `supabase.sql` и нажми **Run**.
4. Открой **Project Settings → API**.
5. Скопируй `Project URL` и `anon public` key. Не используй `service_role` key и никому его не отправляй.

## 3. Подключи переменные в Vercel
1. Загрузи папку проекта в GitHub.
2. В Vercel нажми **Add New → Project** и выбери этот репозиторий.
3. В **Environment Variables** добавь:
   - `VITE_SUPABASE_URL` = Project URL из Supabase
   - `VITE_SUPABASE_ANON_KEY` = anon public key
4. Нажми Deploy.

## 4. Как играть вдвоём
1. Открой сайт на первом телефоне, выбери персонажа и нажми **Создать новую семью**.
2. Передай брату шестизначный код комнаты.
3. Брат открывает тот же сайт на своём телефоне, выбирает Александра и вводит код.
4. События и сообщения сохраняются в общей комнате.

## Важно
Это ранняя игровая версия, а не законченная большая 3D-игра. В текущей версии синхронизируются базовые события и сообщения. Код комнаты работает как простой доступ к комнате: не публикуйте его посторонним. Для публичной игры понадобятся полноценные аккаунты, права доступа и серверная проверка действий.

Если Supabase ещё не настроен, сайт открывается в демо-режиме, но разные телефоны не будут синхронизироваться.
